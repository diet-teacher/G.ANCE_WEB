## 공개 전 소유자 확인

- [ ] 실제 도메인과 공식 홈페이지 명칭 사용 권한
- [ ] 인스타그램과 지도 링크가 본 매장인지, 주소가 최신인지 대조
- [ ] 정확한 Google Maps 장소 ID 링크, 네이버 플레이스 공식 URL
- [ ] 제공 서비스명, 방식별 설명·차이, 가격과 포함 항목, 소요시간
- [ ] 예약 플랫폼 URL, 예약금·취소·변경 정책
- [ ] 영업시간·휴무·전화번호·주차 및 건물 진입 안내
- [ ] 운영자 이력·자격과 영업 정보 및 게시가 필요한 사업자 표시사항
- [ ] 업종·서비스에 적용되는 영업 및 광고 규정과 문구 적합성 확인
- [ ] 로고 원본·매장 사진·실제 작업 사진·설명·권리 및 게시 동의
- [ ] 좌표는 검증된 지도 자료가 있을 때만 geo에 추가
- [ ] 운영 정보가 확인되면 HTML·JSON-LD·공식 외부 프로필 동시 갱신
